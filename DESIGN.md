# Profile design

The profile combines three Awesome GitHub Profile templates on the navy/blue theme:

1. Neural Pulse Lattice: the animated hero banner. Its network is decorative; its text names actual project methods rather than invented runtime statistics.
2. Analytics Grid: four metrics and a 90-day chart computed from actual GitHub data.
3. Snake Eat Graph: generated by Platane/snk from the GitHub contribution calendar, with blue/light and navy/dark variants.

Project cards and the footer keep the earlier navy palette; methods and project descriptions remain editable Markdown. Skill Icons are hosted in the repository. The large intro image was replaced with native Markdown for easier reading.

## Automatic activity refresh

`.github/workflows/profile-visuals.yml` publishes generated SVGs to `profile-assets` daily at 21:23 UTC (06:23 Asia/Seoul). It also supports manual runs. See [ACTIVITY.md](./ACTIVITY.md) for metric definitions, permissions, data handling, and refresh behavior.

The README loads the three template sections from that generated branch. The source renderer is `scripts/profile-visuals.mjs`; original artwork is preserved under `vendor/awesome-github-profile/`. All placeholder metrics are replaced with GitHub contribution-calendar and public pull-request data. Failed runs preserve the prior successful images.

## Updating the other cards

With Node.js 22.18 or newer:

```sh
node scripts/build-profile.mjs
```

This separate script regenerates the earlier RyMe-based panels, project cards, and footer. The active README embeds its project cards and footer; the older header/about panels remain available but are not embedded.
